\section{Conclusion}
\label{sec:conclusion}

This paper presented the first causal measurement framework evaluating browser anti-fingerprinting defenses via programmatic Real-Time Bidding clearing prices. 
Across 150 commercial publishers, stateful profile clearing alone yielded an imperceptible $-1.12\%$ bid drop ($p = 0.4832$), confirming Demand-Side Platforms routinely bypass storage resets using stateless fingerprinting~\cite{acar2014web, liu2025first}.

Defenses disrupt tracking along an empirical Pareto frontier: (1)~\textbf{Hardened Firefox} achieves the \textit{Stealth Optimum} ($-26.86\%$ median bid collapse, $p = 0.0734$, 810 hosts) with zero excess exception overhead ($\ucost = 0.00$); while (2)~\textbf{Hardened Brave} achieves the \textit{Apex Disruption Optimum} ($-59.98\%$ collapse, $\rid = 0.500$), at the cost of a $+44\%$ surge in runtime script exceptions ($\ucost = 0.44$).

Our refined metric ($\etr$) resolves the ``Usability Trap,'' demonstrating that defensive request blocking triggers tracker retry loops. To preserve functionality while defending privacy, browser vendors should favor API normalization over aggressive network blocking~\cite{iqbal2020adgraph, tor_design}. 
In accordance with reproducibility standards~\cite{demir2022reproducibility}, we open-source our testbed and auction datasets.
