\subsection{Programmatic Advertising \& Header Bidding}
Modern web publishers monetize digital inventory via programmatic Real-Time Bidding (RTB). While legacy display monetization relied on monolithic ad servers (e.g., Google Ad Manager), modern publishers deploy \textbf{Header Bidding} wrappers, principally the open-source \texttt{Prebid.js} framework, embedded directly in the client-side DOM~\cite{pachilakis2019imc, cook2020popets}.

As illustrated in Figure~\ref{fig:ad_lifecycle}, when a client navigates to a publisher:
\begin{enumerate}
    \item \texttt{Prebid.js} dynamically reads configuration tags, identifies eligible ad slots, and issues parallel, asynchronous HTTP bid requests to configured Supply-Side Platform (SSP) adapters (e.g., Rubicon, OpenX, AppNexus).
    \item Each SSP adapter forwards the bid request via OpenRTB protocols to participating Demand-Side Platforms (DSPs). This request encapsulates client attributes: geographical metadata, viewport dimensions, cookie-sync identifiers, and stateless device fingerprint signals collected by embedded tracker scripts~\cite{papadopoulos2019conrad}.
    \item DSP bidding algorithms parse the payload and query internal identity graphs. If the payload matches a high-intent user persona, the DSP bids aggressively. If the payload cannot be linked to historical data, the DSP bids at contextual reserve floors~\cite{barysei2023imc}.
    \item Winning bids return to the browser, where \texttt{Prebid.js} resolves the highest clearing \cpm, surfaces it to the publisher's ad server, and renders the ad creative.
\end{enumerate}

\subsection{The Economic Targeting Premium}
The bedrock econometric assumption of digital ad tech is that identified users command significantly higher prices than anonymous users. Longitudinal empirical studies by Beales and Eisenach demonstrated that behavioral-targeted advertising sells for a $2.68\times$ price premium over non-targeted advertising ($+168\%$)~\cite{beales2014navigant}. 

Subsequent field trials by Google confirmed that stripping user identifiers precipitously decreases publisher ad revenue by an average of $52\%$~\cite{google2019cookies}, a finding echoed by Johnson et al. ($54\%$ revenue decline)~\cite{johnson2020marketsci}. 

Consequently, we formalize clearing \cpm as an \textit{economic side-channel oracle}:
\begin{equation}
\cpm(u) = \alpha \cdot \mathbb{I}_{\text{identified}}(u) + \beta_{\text{context}} + \epsilon_{\text{market}}
\end{equation}
where $\alpha$ represents the behavioral targeting premium ($\alpha > 0$), $\beta_{\text{context}}$ represents base contextual inventory value, and $\epsilon_{\text{market}}$ denotes stochastic auction noise.

\subsection{Threat Model}
\paragraph{Adversarial Capabilities}
We model commercial tracking consortiums, SSPs, and DSPs as curious-but-honest commercial observers. The adversary operates JavaScript code embedded within publisher domains, participates in programmatic auctions, and seeks to persist user identities across disjoint first-party contexts ($s_i \neq s_j$). 

The adversary has unrestricted access to standard browser Web APIs and executes stateless fingerprinting techniques (Canvas pixel extraction, WebGL parameter enumeration, AudioContext oscillator decay, system font profiling, and WebRTC candidate enumeration). 

\paragraph{Adversarial Boundaries}
The adversary \textit{cannot} compromise the underlying operating system, inspect kernel or process memory, forge TLS cryptographic primitives, or mount machine-in-the-middle network tampering. IP-based location matching is constrained to geographic subnet clustering. 

\paragraph{Client Defenses}
The client executes a modern web browser equipped with anti-fingerprinting defenses (API normalization, API farbling, and defensive network filtering). The user's objective is to enforce an \textit{identity break} by programmatically flushing stateful storage and verifying that stateless defenses prevent re-identification.
