\section{Introduction}
\label{sec:intro}

For two decades, the commercial web's surveillance economy operated on stateful storage primitives: HTTP cookies~\cite{rfc6265, rfc7231, rfc9110}, HTML5 Web Storage~\cite{whatwg_webstorage}, and persistent database caches~\cite{lerner2016internet}. 
In response to consumer pushback and regulatory mandates, major browser vendors introduced storage partitioning architectures, notably Apple WebKit's Intelligent Tracking Prevention (ITP) and Mozilla Gecko's Total Cookie Protection (dFPI)~\cite{papadogiannakis2021user, randall2022measuring}. 
As third-party cookies decay, tracking consortiums have systematically pivoted to \textbf{stateless browser fingerprinting}~\cite{mowery2012pixel, nikiforakis2013cookieless, acar2014web, cao2017cross, bujlow2017survey, laperdrix2020browser}: interrogating hardware, driver, and OS-level attributes through standard Web APIs (Canvas, WebGL, AudioContext, WebRTC, and fonts) to reconstruct persistent cross-site behavioral graphs.

To counteract stateless tracking, modern browsers deploy two diverging philosophies: \textbf{API Normalization} (pioneered by Tor Browser~\cite{tor_design, torbrowser_normalization_2019} and Mozilla RFP~\cite{mozilla_rfp_docs}), which quantizes execution timers and homogenizes system metrics to maximize client anonymity sets; 
and \textbf{API Randomization} (implemented by Brave Farbling~\cite{brave_fingerprinting_protections_2025}), which injects pseudo-random noise into canvas and audio readbacks to disrupt cross-session linking.

Despite these deployments, the measurement literature lacks an empirical framework to determine whether these defenses functionally protect users in production. Current benchmarks suffer from two structural flaws:
\begin{enumerate}
    \item \textbf{The Intent vs.\ Outcome Fallacy:} Passive measurement platforms (e.g., FPDetective~\cite{acar2013fpdetective}, OpenWPM~\cite{englehardt2016openwpm}, FP-Inspector~\cite{iqbal2021fingerprinting}) log API execution heuristics, measuring tracking \textbf{intent} rather than tracking \textbf{success};
    observing an executed canvas readback provides zero verification that the extracted signal resolved a user within an ad-tech graph.
    \item \textbf{The Theoretical Entropy Gap:} Synthetic benchmarks (e.g., Panopticlick~\cite{eckersley2010unique}, AmIUnique~\cite{laperdrix2016amiunique}) calculate Shannon entropy bits removed from isolated APIs, but theoretical entropy reductions do not guarantee tracking severance in the wild; 
    if trackers combine a partially farbled canvas with residual cross-site signals (IP subnet, TLS fingerprints, User-Agent), re-identification persists~\cite{vastel2018fp, sjosten2021essentialfp}.
\end{enumerate}

\paragraph{Real-Time Bidding as an Economic Oracle}
To overcome the limitations of proxy measurements, we operationalize programmatic Real-Time Bidding (RTB) clearing prices as an economic side-channel oracle~\cite{castelluccia2014selling, bashir2016tracing, liu2025first}. 
In header bidding auctions orchestrated via client-side Prebid.js wrappers, algorithmic Demand-Side Platforms (DSPs) submit bids (Cost Per Mille, or \cpm) within milliseconds based on identity certainty~\cite{pachilakis2019no, cook2020inferring}. 
Econometric studies establish that an identified user commanding a rich cross-site behavioral profile sells for a $30\%$ to $60\%+$ valuation premium over an untargeted contextual impression~\cite{beales2014empirical, johnson2020consumer, google2019cookie}. 
When an anti-fingerprinting defense successfully breaks cross-site tracking across an enforced stateful reset, DSP identity graphs are severed, causing bidding algorithms to retreat to contextual reserve floors~\cite{barysei2023investigating}.

\paragraph{Contributions}
Deploying a cluster-scale causal measurement harness driving native Linux browser binaries across 150 commercial publishers, this work delivers four contributions:
\begin{itemize}
    \item \textbf{Causal Measurement Methodology:} We design a 3-phase experimental protocol that trains high-intent personas, records baseline bids, purges stateful storage, and measures post-purge economic bid shifts, isolating stateless tracking in the wild.
    \item \textbf{Validation of the Negative Control:} Unhardened Chrome yields a negligible median bid shift of \textbf{$-1.12\%$} ($p = 0.4832$, fail to reject $H_0$), demonstrating empirically that stateful clearing without anti-fingerprinting defenses provides no protection against modern ad tech.
    \item \textbf{The Empirical Pareto Frontier:} We identify an operational trade-off: \textit{Hardened Firefox} achieves the \textbf{Stealth Optimum} ($-26.86\%$ median bid collapse, $p = 0.0734$) with zero usability breakage ($\ucost = 0.00$), whereas \textit{Hardened Brave} achieves the \textbf{Apex Disruption Optimum} ($-59.98\%$ collapse, $\rid = 0.500$), but incurs a $+44\%$ surge in runtime script exceptions ($\ucost = 0.44$).
    \item \textbf{Metric Refinement ($\etr$):} We demonstrate that defensive request blocking triggers tracker retry loops ($28,976$ events in Firefox Hardened) that invert naive metrics. We formalize the Refined Effective Tracking Resistance metric ($\etr$), restoring methodological rigor to web defense benchmarking.
\end{itemize}
